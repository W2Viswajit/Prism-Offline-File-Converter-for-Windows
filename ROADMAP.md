# Editable roadmap

## Delivered v0.1 beta
- [x] Offline Python/Qt desktop app, dark/light/system appearance
- [x] Conversion wheel with separate image tools wheel
- [x] Main-window file picker and file drop area
- [x] Image conversion, crop, resize, rotate, compression
- [x] Images to PDF, PDF pages, PDF to PNG, text extraction
- [x] Printed-text OCR as an optional install
- [x] DOCX rendering adapter for optional LibreOffice
- [x] Local text review/copy and revised-copy save
- [x] Source ZIP, setup/launch/debug scripts, executable build recipe
- [x] Automated engine and Qt tests; sample files

## Windows acceptance gate
- [ ] Run Setup and launch on Windows 11/Python 3.12
- [ ] Validate Explorer Ctrl+Alt+Space and Shift-drag actual OLE drops
- [ ] Check native backdrop and clipping on Windows compositor
- [ ] Check 100%, 125%, 150% display scaling and multiple monitors
- [ ] Check DOCX layouts with installed fonts/LibreOffice
- [ ] Build/test the base standalone executable on a clean machine
- [ ] Verify screen-reader behavior and high-contrast/reduced-motion handling

## V1 polish after laptop feedback
- [ ] More refined material treatment/hover motion against real desktops
- [x] Per-user classic right-click entry with an uninstall script (v0.1.1)
- [ ] Modern Windows 11 menu extension and optional startup toggle
- [ ] Customizable wheel favourites and hotkeys
- [ ] Crop handles, aspect-ratio presets and numeric crop values
- [ ] Memory/performance profiling with real user files
- [ ] Durable job history and recovery queue
- [ ] Improve explicit colour/metadata preservation options

## V2
- [ ] Background styling, padding, corners and shadows
- [ ] Annotation and true content-removing redaction
- [ ] More document formats and improved OCR
- [ ] Saved recipes and folder batches
- [ ] Target-size compression previews
- [ ] Video and audio only after core features are stable

Sharing, WhatsApp, QR transfer and cross-device clipboard are excluded.
